# Fardin-s-Portfolio

The source for **fardin.ai**, the personal portfolio of **Md. Fardin Hossain**.

This repository contains the complete static website: authored JavaScript/CSS, theme-specific portraits, project and certificate images, PDF attachments, an inspection preview, local launchers, and browser verification tooling.

## Current interface

- Responsive Hero using the supplied light/dark portrait compositions, selected when the theme changes.
- Compact condensed name with coral-highlighted FARDIN; on mobile, the name overlays the lower portrait.
- Reference-inspired navigation with WORKS, ABOUT, EXPERIENCE, CONTACT, a theme control and a split contact button.
- A real procedural Three.js robot with reduced-motion support and safe mobile movement.
- Four-chapter editorial About section with the supplied summitscape backdrop, progress navigation, readable word reveals and a five-step development process.
- Existing experience, projects, certification, contact and internship-journey sections.
- Smooth mouse-wheel/navigation scrolling with native touch and keyboard behavior and a native fallback.

No statistics or achievements are generated by the visual effects. The journey's sample ranker is an illustrative client-side calculation, not live model inference. Narrative claims and linked credential/PDF content are portfolio material, not independently verified by the UI tests.

## Run locally

The application is a **no-build static React site**. It uses browser ES modules and React.createElement, not a Node production server or JSX compilation.

### Quick start

Python 3 is required for the launchers:

- **Windows:** extract/clone the project and double-click `START_PREVIEW.bat`.
- **macOS/Linux:** run `sh start-preview.sh`.

Open **http://localhost:4175**. Keep the server window open; Ctrl+C stops it. The server binds to 127.0.0.1 only. If port 4175 is occupied, stop the existing server first.

Or start it directly:

```sh
git clone https://github.com/fardinhossain/Fardin-s-Portfolio.git
cd Fardin-s-Portfolio
python3 -m http.server 4175 --bind 127.0.0.1
```

Internet is required for the existing pinned esm.sh libraries and Google Fonts. Serve the repository from the origin root; direct file:// loading of `index.html` is not supported.

### Single-file inspection preview

`PREVIEW.html` is generated from the source and can be opened directly in a browser without running the server. It still requires internet for CDN libraries/fonts and unchanged public attachments. New theme portraits, scenery, authored modules and styles are embedded.

The inspection preview disables contact submission to prevent accidental delivery and uses hash routing inside its host. The actual source retains its existing Formspree contact behavior. It is not an offline build or a replacement for the source.

Regenerate it with:

```sh
python3 verification/build-browser-preview.py PREVIEW.html
```

## Verify

The optional test tooling has its own package and lockfile; it is not required to serve the portfolio.

```sh
cd verification
npm ci
npx playwright install chromium
npm test
```

The suite starts an ephemeral loopback server and writes generated captures under `verification/artifacts/` (Git-ignored). It covers the eight requested widths in both themes, correct theme portraits, name placement, chapter and theme interactions, WebGL fallback/lifecycle, text spacing and smooth-scroll behavior. The latest suite has **47 passing cases** in Chromium using software WebGL.

No production build, lint or type-check scripts are defined in this plain-JavaScript application. Browser checks are not physical-device, hardware-performance, complete-site accessibility, contact-delivery or credential-authenticity certification.

## Hosting

`vercel.json` configures clean URLs and maps `/journey` and `/experience/flyrank-ai` to the main application. A basic Python static server does not reproduce every clean-URL rewrite; the corresponding HTML files remain available directly.

Publishing this repository does not by itself deploy a new live website. The existing portfolio URL is https://fardinflyrankai.vercel.app/; deployment of this repository must be configured separately.
